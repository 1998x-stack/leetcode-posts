# 题解编写准则

先以原创语言复述题目，不复制完整官方题面。逐条标注输入约束、状态不变量、代码行与图示间的对应关系。图示默认状态应该可理解，交互不能代替叙述。至少覆盖一般例、最小边界例、重复/无解例；声明空间复杂度是否包含返回结果。所有 SVG 要可独立打开且不依赖远端图片。

## 基础专题的教学标准

- **数组与哈希表**：明确已扫描前缀代表什么；哈希表存储值、索引还是计数；平均/期望复杂度假设；是否修改输入。
- **二分查找**：每篇必须声明闭区间或半开区间、循环条件、区间不变量、mid 归属和每条边界更新的理由。边界题要区分 lower bound 与 upper bound。
- **二叉树**：先定义递归函数返回值，再写基例和组合关系；说明 DFS/BFS 选择依据；区分节点高度与边数路径；递归栈按树高 h 分析。
- 每个交互演示至少包含一个边界或反例状态；静态 SVG 先讲清结构，交互只负责展示状态转移。
- 题解需要给出从朴素方法到优化方法的迁移，而不是直接展示最终代码。
