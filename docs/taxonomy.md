# 算法分类规范

每篇文章只有一个主分类和一个稳定二级专题；次要模式通过 tags 交叉检索。分类由文章的核心证明与学习目标决定，不由代码中偶然出现的数据结构决定。

| 主分类 | 核心问题结构 | 专题示例 |
|---|---|---|
| 双指针 | 有序候选的安全排除 | 对向双指针、排序与去重 |
| 滑动窗口 | 连续区间状态维护 | 可变长窗口、频率窗口 |
| 回溯与搜索 | 选择路径、递归和撤销 | 排列、剪枝 |
| 图与网格 | 可达性、连通性、图遍历 | 网格遍历、最短路径 |
| 二分查找 | 有序区间或单调判定 | 旋转数组搜索 |
| 动态规划 | 子问题重叠与最优子结构 | 完全背包 |
| 单调栈 | 新元素批量解决未完成查询 | 下一个更大元素 |
| 树与遍历 | 父子关系、深度和层级 | 层序 BFS |
| 数据结构设计 | 多结构协同维护操作不变量 | LRU 缓存 |

## 归类原则

- 树的层序遍历归入“树与遍历”，因为核心产物是按树深度分组；网格连通块归入“图与网格”。
- LRU 归入“数据结构设计”，因为核心在哈希映射与双向链表之间维护一一对应及最近使用顺序。
- 单调栈按“尚未解决的查询”分类，不按一般栈操作分类。
- 只有当一个主题能够指导后续文章并具有清晰定义时才新增分类。不要为单篇文章制造过细分类。
- slug 一旦发布即视为稳定 URL；合并主题时保留旧 URL 并更新导航，不直接删除文章。
