# Contributing

1. Read AGENTS.md and skills/olah-style-leetcode-posts/SKILL.md.
2. Read `docs/taxonomy.md`; pick one registered category/topic and one primary home only. Create a draft and reference the official LeetCode problem URL.
3. Add original explanation, 3 standalone SVGs, deterministic solution.py and tests.
4. Fill all controlled `facets` from `content/facets.json`; explain the invariant, correctness, time/space and edge cases. Cite the original problem, not copied problem statements.
5. Run build, pytest, static validation, browser QA and skill-mirror check. Submit a PR; do not publish a draft.
