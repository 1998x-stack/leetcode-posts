01 · 题意与直觉

一个由字符 '1'（陆地）和 '0'（水）组成的网格，相邻只考虑上下左右。例子 4×5 网格中，有左上连成一片、中央单格和右下两格，总共 3 座岛。

先想一想：为什么不直接暴力枚举？

对每个陆地格都单独搜索会重复统计相同连通块。需要保证一个岛屿的所有格子在首次发现时被一次性标记。

02 · 先说清什么永远不变

循环 / 递归不变量

从某个尚未访问的陆地格启动搜索时，栈里的每个坐标都已标记为已访问；一次搜索会覆盖它所在连通块的全部格子。只有主循环遇到新的 '1' 才将计数加一。

把每个陆地格视为顶点，上下左右相邻的陆地格之间有边。扫描全网格，遇到 '1' 就计数加一并做迭代 DFS；入栈时立即把 '1' 改为 '0'，防止同一格被反复压栈。

04 · 为什么不会漏掉答案？

每个岛屿最先遇到的格子一定触发一次 DFS，因此不会漏数。由于 DFS 沿四邻接边遍历并标记该岛全部可达陆地，同一岛的其他格子之后不会再次触发计数。不同岛之间不存在陆地路径，所以一次 DFS 绝不会错误合并两座岛。

05 · Python 参考实现

下面使用 LeetCode 的 class Solution 接口。源代码同时保存在仓库的 solution.py 中，并由确定性测试覆盖主要边界。

class Solution:
    def numIslands(self, grid: list[list[str]]) -> int:
        if not grid or not grid[0]:
            return 0
        rows, cols = len(grid), len(grid[0])
        islands = 0
        for row in range(rows):
            for col in range(cols):
                if grid[row][col] != "1":
                    continue
                islands += 1
                grid[row][col] = "0"
                stack = [(row, col)]
                while stack:
                    r, c = stack.pop()
                    for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                        nr, nc = r + dr, c + dc
                        if (0 <= nr < rows and 0 <= nc < cols
                                and grid[nr][nc] == "1"):
                            grid[nr][nc] = "0"  # 入栈即标记
                            stack.append((nr, nc))
        return islands

时间与空间复杂度

维度分析
时间 / 空间时间 O(mn)：每个格子检查常数次；最坏额外栈空间 O(mn)。本实现为了节省 visited 集合而原地把访问过的 '1' 改成 '0'，会修改输入网格；如需保留输入，先复制网格或使用额外 visited。
算法范围上述结论以官方输入语义与 Python 常规操作成本为前提；本地演示不代表 LeetCode 排名或运行时百分位。

06 · 一张图记住易错点

对角相邻不算同一岛。若在格子出栈后才标记，多个邻居可能重复压入它；应在入栈时立即标记，以稳定保证每个格子至多入栈一次。
