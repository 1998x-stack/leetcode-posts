LeetCode 102 · 二叉树的层序遍历

先处理完这一层，再看下一层：队列如何守住层级边界？

中等 Medium13 分钟Tree

LeetCode 官方原题 ↗返回全部题解 ↗

01 · 题意与约束

根节点 3，左孩子 9、右孩子 20，而 20 的孩子为 15 和 7。层序结果为 [[3],[9,20],[15,7]]；空树返回空数组。

02 · 从朴素思路走向优化

DFS 也能访问每个节点，但要按层输出还需记录深度并分组。BFS 的队列天然按深度递增，因此可直接逐层收集。

使用 deque。每轮先读取 level_size，固定次数弹出节点、记录值，并按左孩子再右孩子的顺序把孩子加入队尾。当前层完成后，将 level_values 放入结果。

03 · 核心状态与不变量

每一步都必须保持

开始处理某层时，队列恰好是这一层从左到右的所有节点。先保存当前队列长度 level_size，再恰好弹出这么多个节点；它们的孩子只会进入下一层。

05 · 为什么算法正确？

根节点深度为 0。FIFO 保证浅层节点先于其孩子出队。每轮固定 level_size 后，新加入的下一层节点不会在本轮被处理，因此本轮恰好收集同一深度，并保持从左到右顺序。每个节点只入队、出队一次。

06 · Python 参考实现

下面是完整的 LeetCode 兼容实现。树节点由评测环境提供；LRU 的链表节点在解法中显式定义。

from collections import deque

class Solution:
    def levelOrder(self, root):
        if root is None:
            return []
        result = []
        queue = deque([root])
        while queue:
            level_size = len(queue)
            level_values = []
            for _ in range(level_size):
                node = queue.popleft()
                level_values.append(node.val)
                if node.left is not None:
                    queue.append(node.left)
                if node.right is not None:
                    queue.append(node.right)
            result.append(level_values)
        return result

时间与空间复杂度

设 n 为节点总数、w 为最大层宽。时间 O(n)，辅助队列 O(w)，返回的二维数组另占 O(n)。

07 · 一个边界条件，足以改变答案

不要在当前层处理中动态地以 while queue 非空作为本层条件，否则新加入的孩子也会被立即处理，层级会混在一起。必须冻结 level_size。使用 deque.popleft()，不要反复 list.pop(0)。
