# 二分查找

二分查找不是“取中间数”这么简单。它依赖有序性或单调判定，并要求区间定义、循环条件和边界更新严格一致。

## 学习顺序
1. **精确查找** — LeetCode 704：闭区间 [left, right] 与 while left <= right。
2. **边界查找** — LeetCode 34：半开区间 [lo, hi)，区分 lower_bound / upper_bound。
3. **旋转数组** — LeetCode 33：判断哪一半仍然有序，再排除不可能的一半。

## 每篇都必须说清
- 搜索区间包含哪些位置？
- 循环条件为什么是 < 或 <=？
- mid 被保留还是被排除？
- 每次边界更新如何保持不变量？
- 区间为空意味着什么？何时返回答案或 -1？

## 掌握标准
能在不看模板的情况下定义区间不变量；能处理单元素、空数组、首尾命中和不存在；能区分精确查找与边界查找。
