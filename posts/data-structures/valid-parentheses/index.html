有效的括号

01 · 先弄清楚题目要做什么

给定只包含 ()、[]、{} 的字符串，判断括号是否有效。每个左括号必须由同类型右括号闭合，闭合顺序必须正确，最后不能留下未匹配的左括号。例：([]) 有效，([)] 无效。

先抓住核心：栈顶必须是最近一个尚未闭合的左括号：嵌套结构天然遵循后进先出。

02 · 从朴素方法出发

统计每种括号数量无法保证嵌套顺序正确。括号的关闭顺序是后进先出：最后打开的括号必须最先关闭。栈恰好保存尚未匹配的左括号。

优化不是背模板，而是识别输入中可复用的信息：能否记录已经见过的内容？能否维护一个规模受控的候选集合？能否安全地排除不可能的状态？

03 · 状态与不变量

扫描到任意位置时，栈从底到顶保存当前前缀中尚未匹配的左括号，顺序与打开顺序一致。遇到右括号，必须与栈顶类型匹配并弹出；若栈空或类型不符，立即无效。结束时栈必须为空。

05 · 为什么算法正确

栈始终精确表示尚未闭合的左括号。任何合法嵌套都必须先关闭最近打开的左括号，因此右括号只能匹配栈顶；栈空或类型不符时无法修复。结束时栈非空意味着有左括号未闭合。若从未出现不匹配且最终栈空，则每个括号都按正确顺序闭合。

正确性来自状态不变量：每次更新都保持它，终止时它恰好推出题目要求的结果。

06 · Python 参考实现

实现与上面的状态定义及证明一一对应。

class Solution:
    def isValid(self, s: str) -> bool:
        pairs = {")": "(", "]": "[", "}": "{"}
        stack = []
        for char in s:
            if char in pairs:
                if not stack or stack.pop() != pairs[char]:
                    return False
            else:
                stack.append(char)
        return not stack

复杂度分析

设 n 为字符串长度。每个字符至多入栈一次、出栈一次，时间 O(n)。最坏全是左括号，栈占 O(n) 辅助空间。

07 · 反例与边界检查

([)] 的数量可能平衡，但顺序不合法；必须比较栈顶类型。弹栈前检查栈是否为空。空字符串扫描后栈为空，按定义有效。
