# 数据结构与设计

从哈希表、栈、链表和堆等基础结构出发，理解访问顺序、指针更新、候选维护与多结构协作。

## 已发布专题

- **栈与括号匹配** — LeetCode 20：用后进先出顺序验证嵌套结构。
- **链表反转与指针重连** — LeetCode 206：用 prev / curr / next 安全地反转 next 指针。
- **堆与 Top-K 优先队列** — LeetCode 347：用容量为 k 的最小堆维护高频候选。
- **LRU 缓存** — LeetCode 146：哈希表与双向链表协作维护访问顺序。

## 学习问题

- 栈为何天然适合最近打开、最先关闭的括号？
- 为什么反转链表前必须先保存 curr.next？
- Top-K 问题为什么用最小堆，而不是始终保存全部排序结果？
- 堆顶为什么恰好是当前候选中应该优先淘汰的元素？
- 如何从单链表指针重连迁移到双向链表的节点摘除与移动？

## 掌握标准

能够画出栈的 push/pop 轨迹；能够说明链表反转循环开始时的 prev/curr 不变量；能够证明容量为 k 的最小堆始终保留已扫描元素中频率最高的 k 个。
