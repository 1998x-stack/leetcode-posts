反转链表

用 prev、curr、next 三个引用：先保存后继，再把当前指针反向连接。

Easylinked-list-reversal可视化题解

LeetCode 官方原题 ↗

01 · 先弄清楚题目要做什么

给定单链表头节点 head，将所有 next 链接反转并返回新头节点。例：1 → 2 → 3 → 4 → 5 → None，变为 5 → 4 → 3 → 2 → 1 → None。空链表和单节点链表也必须正确。

先抓住核心：用 prev、curr、next 三个引用：先保存后继，再把当前指针反向连接。

02 · 从朴素方法出发

把节点值复制到数组再逆序重建，会额外使用 O(n) 空间，也没有复用原节点。更直接的方法是逐个修改 next，让已处理前缀逐渐反向。

优化不是背模板，而是识别输入中可复用的信息：能否记录已经见过的内容？能否维护一个规模受控的候选集合？能否安全地排除不可能的状态？

03 · 状态与不变量

每轮开始时，prev 指向已反转部分，curr 指向未处理部分的第一个节点，next 暂存 curr 原来的后继。先保存 next，再令 curr.next = prev，最后推进 prev 和 curr。两个部分始终分离，不会丢失节点。

以下是标准样例的确定性关键帧，不是对任意输入的在线执行。图形、步骤说明和不变量来自同一份快照数据。

05 · 为什么算法正确

初始 prev 为空，已处理部分为空，满足不变量。每轮先保存 curr.next，保证未处理部分仍可访问；再把 curr 接到已反转部分前端。推进指针后不变量继续成立。循环结束 curr 为空，所有原节点都已进入 prev，且链接方向完全反转，返回 prev 即正确。

正确性来自状态不变量：每次更新都保持它，终止时它恰好推出题目要求的结果。

06 · Python 参考实现

实现与上面的状态定义及证明一一对应。

# LeetCode provides ListNode and Optional.
class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        prev = None
        curr = head
        while curr:
            next_node = curr.next  # 先保存未处理部分
            curr.next = prev       # 反转当前链接
            prev = curr            # 已反转部分向前扩展
            curr = next_node       # 继续处理剩余节点
        return prev

复杂度分析

设 n 为节点数。每个节点只访问一次并修改一次 next，时间 O(n)。只使用 prev、curr、next 三个引用，额外辅助空间 O(1)，原地复用节点。

07 · 反例与边界检查

若先覆盖 curr.next 而不保存原后继，后续节点会失去入口。空链表返回 None；单节点链表原样返回。反转链表是改变节点链接，不是交换节点值。
