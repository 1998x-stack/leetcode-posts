# 二叉树

按树的结构组织递归与遍历：先定义子树返回什么，再选择 DFS 或 BFS，并明确节点高度、路径长度和递归栈的含义。

## 学习顺序
1. **递归定义与树高** — LeetCode 104：空树基例、左右子树结果、节点数深度。
2. **层序遍历** — LeetCode 102：队列、BFS、每层的边界快照。
3. **后序信息汇总** — LeetCode 543：返回子树高度，同时更新经过当前节点的最长路径。

## 这一专题要回答的问题
- 递归函数返回的是高度、节点数、路径和，还是布尔状态？
- 为什么基例必须与返回值的定义一致？
- 什么时候需要先处理孩子，再汇总当前节点？
- BFS 如何区分当前层与下一层？
- 高度按节点数还是边数？路径长度按节点还是边数？

## 掌握标准
能独立写出空树基例与递归组合关系；能解释 DFS 与 BFS 的选择；能固定每层队列长度；能把递归栈按 O(h) 分析，并区分高度与直径的单位。
