LeetCode 15 · 三数之和

先排序，再固定一个数：如何在线性扫描中去重？

中等 Medium16 分钟Sorting

01 · 题意与直觉

输入 [-1,0,1,2,-1,-4]，排序得到 [-4,-1,-1,0,1,2]。互不重复的三元组是 [-1,-1,2] 和 [-1,0,1]，每组之和均为 0。

先想一想：为什么不直接暴力枚举？

枚举三种下标的组合是 O(n³)，还要额外对结果去重。排序后可以把最内层两层降为一次双指针扫描。

02 · 先说清什么永远不变

循环 / 递归不变量

固定排序数组中的位置 i。left=i+1，right=n-1。未扫描的候选位于 [left,right]；当和偏小时，left 向右会使和不减；偏大时，right 向左会使和不增。

排序后依次固定首项 a[i]，在剩余有序区间寻找两数之和 = -a[i]。命中时收录三元组，然后左右同时移动，跳过与刚才相同的值。外层也跳过相同的 a[i]，避免重复答案。

04 · 为什么不会漏掉答案？

对固定 i：和太小时，当前 left 与任意更小/等于 right 的右数搭配都不可能达到目标，故可丢弃 left；和太大时对 right 对称。命中时仅跳过重复值，因为重复值会产生相同三元组，不会提供新的数值组合。外层固定值重复同理；所有不同的合法三元组都有其最左首次出现的 i，可被完整扫描发现。

05 · Python 参考实现

下面使用 LeetCode 的 class Solution 接口。源代码同时保存在仓库的 solution.py 中，并由确定性测试覆盖主要边界。

class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        arr = sorted(nums)  # 保留调用者的输入
        result: list[list[int]] = []
        n = len(arr)
        for i in range(n - 2):
            if i > 0 and arr[i] == arr[i - 1]:
                continue
            if arr[i] > 0:
                break
            left, right = i + 1, n - 1
            while left < right:
                total = arr[i] + arr[left] + arr[right]
                if total < 0:
                    left += 1
                elif total > 0:
                    right -= 1
                else:
                    result.append([arr[i], arr[left], arr[right]])
                    left += 1
                    right -= 1
                    while left < right and arr[left] == arr[left - 1]:
                        left += 1
                    while left < right and arr[right] == arr[right + 1]:
                        right -= 1
        return result

时间与空间复杂度

维度分析
时间 / 空间排序 O(n log n)，n 次以内的固定位置，每次左右指针总共 O(n)，整体 O(n²)；这里使用 sorted(nums) 不修改输入，额外 O(n) 用于排序副本（不含输出），结果空间最多 O(n²) 级别。
算法范围上述结论以官方输入语义与 Python 常规操作成本为前提；本地演示不代表 LeetCode 排名或运行时百分位。
